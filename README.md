# Welcome to Artificial Intelligence in Biology (Bio-AI) 🧬🤖

Dear Students,

Welcome to the **Bio-AI** course! Throughout this semester, we will explore how machine learning and deep learning methodologies intersect with genomics, proteomics, biological imaging, and drug discovery.

Because this course includes hands-on programming and computational biology workflows, you are expected to complete the following setup checklist **before our first lecture**. No prior advanced programming experience is required, but having these tools ready will ensure a smooth start.

---

### Pre-Course Checklist & Prerequisites

#### 1. Set Up Your GitHub Account & Bookmark the Repository

We will use GitHub to distribute lecture notes, example code, and assignments.

* **Create an Account:** If you don't already have one, sign up at [github.com](https://github.com/?utm_source=gemini). *(Tip: Use your university email to apply for the [GitHub Student Developer Pack](https://education.github.com/pack?utm_source=gemini) for free developer tools).*
* **Course Repository:** Bookmark and star our official repository:
👉 **[https://github.com/karakaplanm/bio-ai](https://github.com/karakaplanm/bio-ai?utm_source=gemini)**
* Review the repository structure:
* `lectures/` — Weekly slides and theoretical notes
* `examples/` — Hands-on Python scripts and notebooks
* `assignments/` — Homework tasks and practical exercises
* `reading/` — Supplementary biological & AI papers



#### 2. Google Account & Google Colab (Our Primary Computing Environment)

Most of our computational workflows (such as deep learning models and sequence analysis) will run in the cloud to avoid local hardware constraints.

* Ensure you have access to a active Google account.
* Familiarize yourself with **[Google Colaboratory](https://colab.research.google.com/?utm_source=gemini)**.
* Verify that you can open a new notebook, switch runtime to a **T4 GPU** (`Runtime` ➔ `Change runtime type` ➔ select `T4 GPU`), and execute a simple Python command.
* Make sure you have at least a few gigabytes of free space on your **Google Drive** for storing datasets and model checkpoints.

#### 3. Access to Generative AI Tools (Gemini & API Setup)

We will actively use modern LLMs as coding copilots, literature synthesis assistants, and biological reasoning tools.

* **Google Gemini:** Make sure you can access [gemini.google.com](https://gemini.google.com/?utm_source=gemini).
* **Google AI Studio (Optional / Recommended):** Visit [aistudio.google.com](https://aistudio.google.com/?utm_source=gemini) to obtain a free Gemini API key, which we may use for programmatic AI tasks and automated prompt workflows.

#### 4. Optional: Local Python Environment (For Offline Work)

While Google Colab is sufficient for this course, if you prefer running code locally on your laptop:

* Install **Python 3.10+** (or download the [Anaconda / Miniconda Distribution](https://www.anaconda.com/download?utm_source=gemini)).
* Install a code editor such as **[Visual Studio Code](https://code.visualstudio.com/?utm_source=gemini)** with the *Python* and *Jupyter* extensions installed.

---

### What to Bring to the First Class

* A charged laptop with Google Chrome (or your preferred modern browser).
* Verified logins for GitHub and Google Colab.
* An open, curious mind ready to bridge the wet lab with artificial intelligence!

See you in class!

## About the Course

- **Course Title:** Artificial Intelligence in Biology  
- **Level:** Undergraduate / Graduate  
- **Objective:** To explore how AI techniques can be applied in biological research and practice  
- **Topics Covered:**  
  - Fundamentals of AI and machine learning  
  - AI in bioinformatics  
  - Image analysis (microscopy, histology, etc.)  
  - Genomic data analysis  
  - Protein structure prediction & drug discovery with AI
